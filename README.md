# Python Training 🐍

Bem-vindo ao **Python Training**! Este repositório é dedicado à revisão de conceitos essenciais de programação em Python, algoritmos e bibliotecas. Inclui implementações passo a passo de algoritmos de busca e exercícios práticos de validação de dados com Pydantic.

---

## 📌 Tópicos Abordados

* **Estruturas e Algoritmos (`estruturas-algoritimos`)**
  * **Busca Binária (`Busca_binaria`):** Implementações iterativas, manipulação de ponteiros (`esquerda` e `direita`) e variações com contagem de passos.
  * **Busca Linear (`Busca_linear`):** Algoritmos de busca sequencial e lógicas de correspondência personalizada.

* **Validação de Dados com Pydantic (`Pydantic`)**
  * Modelos básicos de dados e tipagem (*type hints*)
  * Validadores de campos (`Field`) e validadores personalizados de modelos
  * Criação de modelos e manipulação de ficheiros JSON (`person.json`)
